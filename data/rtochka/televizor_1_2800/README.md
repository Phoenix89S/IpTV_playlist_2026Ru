# RTOCHKA — TELEVIZOR 24 TOCHKA

Автоматический диапазон сканирования:

`1.m3u8` — `2800.m3u8`

## Файлы

- `televizor_1_2800.m3u` — полный сгенерированный M3U со всеми 2800 URL
- `televizor_1_2800_full.json` — полный результат анализа
- `televizor_1_2800_report.csv` — табличный отчёт
- `televizor_missing.txt` — URL, которые не были распознаны как M3U8
- `scan_summary.json` — сводная статистика
- `scanner.log` — журнал выполнения

## Основной URL

https://streaming.televizor-24-tochka.ru/live/

## HTTP Referer

https://televizor24tochka.ru/

## Диапазон

1-2800

## Важно

Итоговый M3U содержит все URL диапазона 1-2800,
независимо от результата проверки.

Если название канала не обнаружено внутри M3U8,
используется:

`Канал N`

Сам видеопоток и его сегменты сканером не скачиваются.
Анализируется содержимое M3U8 playlist.
